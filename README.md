# MarciScores

Színes, prémium magyar futballközpont – Kotlin + Jetpack Compose.

## API-kulcs beállítása
1. Nyisd meg a projekt gyökérkönyvtárában a `local.properties` fájlt.
2. Add hozzá ezt a sort (a saját kulcsodat csak a saját gépeden):
   `STATPAL_API_KEY=IDE_A_SAJAT_STATPAL_KULCSOD`
3. A `local.properties` fájl gitignore-ban van, ezért nem kerül fel a GitHubra.

A projekt első induló képernyője jelenleg UI-alap. A következő fejlesztési lépés a StatPal válaszmodell és élő meccsek API-integrációja.
